# Línea de base del Proyecto CRECE

Landing estática con resultados agregados del estudio sociodemográfico de línea de base del Proyecto CRECE.

La publicación presenta la caracterización de 506 personas encuestadas en Lima Metropolitana, Callao y Tumbes, junto con análisis de perfiles, intersecciones, acceso a derechos y una ficha técnica del estudio.

## Publicación

El sitio se publica mediante GitHub Pages y no utiliza una base de datos ni un servidor de aplicaciones.
